# 工具链

## uv — 唯一运行入口

- 运行脚本: `uv run xxx.py`
- 运行 CLI: `uv run cyrilux --help`
- 安装包使 entrypoint 生效: `uv add .`
- 添加依赖: `uv add <pkg>`
- 查看依赖树: `uv tree`

**禁止**直接调用 `python` 或 `pip`。

## ruff — 代码检查

- `ruff check` — 检查问题
- `ruff check --fix` — 自动修复（导入排序、未使用导入等）
- `ruff format` — 格式化

**直接调用 `ruff`**，不要套 `uv run ruff`。

已知问题：D415/D107/D102 — 中文句号不被 ruff 识别为结尾，需手动修复。

## pytest — 测试

- 运行测试: `uv run pytest`
- 单文件: `uv run pytest tests/test_xxx.py`
- 覆盖率: `uv run pytest --cov-report=term-missing` 或 `--cov-report=html`

配置在 pyproject.toml: `[tool.pytest.ini_options]`、`[tool.coverage.report]`。

规范:
- 测试放 `tests/`，纯逻辑函数 + 文件类 CLI 命令用 `tmp_path`，不碰真实数据集
- GPU 训练命令、device 层、GUI 不测
- 临时数据一律走 pytest `tmp_path`，测试结束自动删除

## ty — 类型检查

- 运行: `ty check`
- 配置: `[tool.ty.rules]` 在 pyproject.toml

**直接调用 `ty`**，不要套 `uv run ty`。

## coverage — 覆盖率

- 由 pytest-cov 集成，无需单独运行
- 配置: `[tool.coverage.report]` 的 `exclude_also` 在 pyproject.toml
