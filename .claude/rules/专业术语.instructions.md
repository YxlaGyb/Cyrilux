# 专业术语规范

本文档定义本项目代码、文档、讨论中必须使用的术语。不一致的术语会造成混淆和不必要的"翻译"开销。

## 核心计量单位

| 禁止 | 必须 | 原因 |
|------|------|------|
| token / tokens | **positions**（位置数）或 **bytes**（具体字节值） | 本项目以 UTF-8 字节级（vocab_size=256）为基本单位 |
| sequence length / seq_len（位置计数语境） | **positions** | `seq_len` 仍可作为变量名，语义是"位置数"而非"词元数" |
| vocab_size 非 256 的值 | vocab_size = **256** | 字节级 LM，固定 256 |

> 举例: "batch=48, 每序列 128 positions" 而非 "128 tokens"。

## 模型架构

### 双后端结构

| 术语 | 说明 |
|------|------|
| **DensePCNet** / **DensePCConfig** | dense 后端 — 全 matmul 预测编码网络（model/dense/core.py），含 PPA 闭环 |
| **CyreneModel** / **CyreneConfig** | sparse 后端门面 — 页式事件驱动网络（model/model_cyrene.py），内部持有 TensorNeuronPool + LMHead |
| **TensorNeuronPool** | 页式动态神经元池（sparse 核心，model/sparse/tensor_pool.py） |

### Dense 后端（PPA 闭环）

| 符号/术语 | 说明 |
|------|------|
| **PPA** | Perception-Prediction-Action 闭环 — dense 后端的整体架构 |
| L0 → L4 → L2 → L3 → L5 → L6 | 自下而上层级（L4 为主，d_l4=1024） |
| `W_t` | 时间核 — 每层递归，`z[t] += 0.1·W_t @ z[t-1]` |
| **microcolumn** | L5 拆分的微柱（`l5_blocks=4`） |
| `W_diff` | 增量预测 — `dz5 = z5[t] - z5[t-1]` |
| `M_l5` | Foldiak 反赫布去相关矩阵 |
| `soft_norm_preserve` | 软范数保持（0.8–1.2），防溢出的结构化手段 |

### Sparse 后端

| 术语 | 说明 |
|------|------|
| **PageStorage** / **MemoryBudgetError** | 页式槽位分配（neuron/synapse 页，2GB 预算） |
| **NeuronManager** | 神经元创建/修剪/分裂/生长（`grow_hidden_neurons`） |
| **SynapseManager** | 突触创建/`connect_layer`/`synapse_turnover` |
| **ForwardEngine** | `predict_all`/`temporal_topdown_pass`/`compute_free_energy`/`compute_lm_logits` |
| **LearningEngine** | `hebbian_pass`/`hebbian_temporal`/`hebbian_topdown`/`hebbian_lm_head`/`homeostasis_step` |
| **ProjectionManager** | temporal/topdown 连接维护 |
| **PoolQuery** | 只读查询（`get_neurons_by_layer`/`get_activity_stats`） |
| **LMHead** | 语言模型头 — 输出 256 字节 logits |

### 预测编码核心概念

| 符号 | 术语 | 说明 |
|------|------|------|
| `z` | **variable / activity** | 节点活动值 |
| `μ` (mu) | **prediction** | 自下而上/时序/自上而下预测 |
| `ε` (epsilon) | **prediction error** | `z - μ`，驱动学习的核心信号 |
| `π` (pi) | **precision** | 精度权重，由多巴胺调制 |
| `F` | **free energy** | 自由能 = `Σ ½·π_ℓ·‖ε_ℓ‖²`（`compute_free_energy`） |
| `F_out` | **output energy** | 输出能量（CE loss） |

### 神经调质（model/modulation.py）

| 符号 | 术语 | 说明 |
|------|------|------|
| `D` | **dopamine / RPE** | 奖赏预测误差，`compute_dopamine(F_curr, F_prev, beta)` |
| `ACh` | **acetylcholine** | 乙酰胆碱，`compute_ach(uncertainty, beta_0)` |
| `rel` | **relative surprise** | 相对惊喜，多巴胺/乙酰胆碱增益计算输入 |
| | **modulation** | 组合调制 = `combine_modulation(D, ACh)` = `0.5·D + 0.5·ACh` |

## 学习规则（零 autograd）

| 术语 | 说明 |
|------|------|
| **Hebbian update** | `ΔW = η_eff · ε · activity_pre^T`（`hebbian_pass` 等） |
| **Oja's rule** | 权重归一化项，`oja_alpha`/`oja_elasticity` 控制 |
| **BCM rule** | Bienenstock-Cooper-Munro 规则，滑阈 `_theta_*`，`phi = eps·(eps - theta)` |
| **Foldiak anti-Hebbian** | 反赫布去相关（`M_l5`） |
| **homeostatic plasticity** | 稳态可塑性 — EMA 追踪激活分布，自适应调整阈值（`homeostasis_step`/`adjust_thresholds`） |
| **synapse turnover** | 突触更替 |

## FP16 术语一致

| 场景 | 正确表述 |
|------|---------|
| 模型精度 | "fp16 权重" 或 "原生 fp16" |
| 训练方式 | "全程 fp16 训练" 而非 "混合精度" / "AMP" |
| 溢出处理 | "RMSNorm 前置" 或 "soft_norm_preserve / 权重缩放" 而非 "clamp" |
| 数值核心 | "z 全程 fp32（类 AMP fp16-weight/fp32-activation 模式）" |

## 本地命名习惯

| 规则 | 示例 |
|------|------|
| 希腊字母用拼音首字母替代 | `mu` 而非 μ, `epsilon` 而非 ε |
| 文件名的 PC 相关 | `pc_core.py`, `tensor_pool.py`, `page_storage.py` |
| 训练相关 | `train_step()`, `hebbian_pass()` |
| 全程 fp16 相关变量不加 `_fp16` 后缀 | 默认就是 fp16 |

## 禁止使用的术语（Anti-patterns）

| 禁止 | 应替换为 | 原因 |
|------|---------|------|
| token / tokenize / tokenizer | byte / bytes / byte-level | 本项目为字节级 |
| attention / self-attention | 无对应物 — 本项目无 attention 机制 | 用卷积/递归/页式连接 |
| transformer / Transformer | CyreneBackbone / PC backbone | 本项目无 transformer |
| embedding | byte_proj / input projection / one-hot L0 | 输入投影替代 Embedding |
| quantization / QAT | fp16 native | QAT 已移除，全程 fp16 |
| backpropagation / autograd（对 Hebbian 更新路径） | Hebbian update / bp-free | Hebbian 零 autograd |
