# 第 94-100 轮交接 — 行动-后果闭环打通 (具身域)

exp100 首次实现**行动-感知-后果闭环耦合**: 行为偏置 p_fwd 峰值 0.766、
转移误差按动作分化 7 倍 (te_fwd 0.069 vs te_stay 0.010)、生存健康
