# 第 104 轮交接 — 读出端根因链: 训练/生成口径错配, 内容化首次达成

## 一句话结论

"内容天花板"根因不是数据规模、不是表示层容量, 而是 **训练端与生成端
走了不同管线** (z4/z4_next、zh RMS、三阶后分流、soft_norm 四重错配)。
修复后 W_lm 分支生成长字符占比移至常用区: cf 0.62-0.94 (此前 0.000)。
单一样本示例 (chat_life104 stdout 完整 64 字节):
"是䖝鯇。宠物，这些天。宠物，这些天鼎on的关" — 内含真实短语
但前后仍是罕见字/杂字 — 内容化=常用字区间移动, 不是句子。
W_act 分支 (表达) 仍未内容化 — z_bind 槽容量瓶颈, 已定位留待裁决。

- 表示层线性探针: z4 段 ridge 跨拟合 heldout hit1=0.38, 全特征 0.22-0.28

## 诚实边界

- hit1 (字节级) 未破 0.2 — 词串涌现是读出路修复的直接结果, 字节级
  预测精度仍受表示层上限约束 (n-gram ctx=2 上界 0.41)
- W_act 分支未内容化: z_bind 是 32 槽自组织投影, 当前区分度不足以
  映射 700+ 常用字, 输出为 ascii/符号/罕见字混合. 这是系统自组织
  状态的事实描述 — 若需演化由系统自身机制生长 (神经发生/修剪有
  先例), 不人为调维度数值, 按用户决策推进。
- 具身 te_gap 未达 exp100 分化水平, 起点不同 (字节域切片 vs exp100 链)
- ridge 闭式解 = 一次性最小二乘, 不是长期训练机制; 但证明读出路
  可达 0.26+ 且 Hebbian 能从该起点继续
