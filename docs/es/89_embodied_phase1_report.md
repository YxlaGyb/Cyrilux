# 最小具身阶段 1 探针报告 (exp89_emb1)

**轮次**: 第 89 轮 · **日期**: 2026-08-17 · **脚本**: `scripts/exp_embodied1.py`
**起点**: `out/exp85_b100.pt` (exp85 终点, 静息态) · **长度**: 500 learn 步 × 64 agent 步 = 32,000 agent 步

## 一、背景与裁决

第 88 轮裁决 9: 系统在纯自由运行中收敛到**静息态** (bias_l4=54.4 冻结,
slope -1.6~-1.8, sat 57%, env_cv 0.011, 间歇性死亡), 判定为孤立系统的自然
静息态——"一个睡着的婴儿, 不是一具尸体"。**接受它, 不修它, 不动它**; 不再追加
内部机制。

最小具身方案的论题: **静息态不是被"修复"的, 是被"唤醒"的。** 当 L0 不再恒为零、
而是被环境信号驱动时, `mu4 = bias + osc` 不再是一个孤立的固定点——新信号进入
Hebbian 更新, 打破原有平衡, bias 支柱自然松动。执行阶段 1: 一维世界 + 行动-感知
接口 + W_act 维度改造, 短探针 500 步, 验证行动-感知关联是否建立。

## 二、设计决策

### 2.1 环境物理 (方案 3.1, 逐条实现)

| 参数 | 值 | 说明 |
|------|-----|------|
| 轨道长度 L | 32 | 一维环形, 无墙 (墙即外部控制器已终结) |
| 能量块 | 4 个随机位置 | 每 T=50 步重排 |
| 电量 | 每步衰减 0.01 | 物理上限 2.0 (方案未指定, 防多块连吃无界) |
| 电量回升 | 与块同格 +0.5 | 仅同格触发, 假动作无法触发 (风险 3 预防) |
| 动作 | 前进 [1,0] / 停留 [0,1] | 最小行动空间, 最短因果链 |

电量是**物理事实, 非优化目标**: 不进入任何目标函数/损失, 只进入感知向量。电量
耗尽 → 环境记录死亡事件 (deaths), 但网络权重保留、循环继续 (静息语义, 方案 4.3)。

### 2.2 感知空间 (方案 3.3)

L0 = 8 维: `[当前格有块, 前方格有块, 后方格有块, 电量, sin(位置), cos(位置),
sin(时间相位), cos(时间相位)]`。替代 256 维字节 one-hot。布尔 0/1、电量 [0,2]、
sin/cos ∈ [-1,1], fp16 全安全。

### 2.3 窗口语义 (与既有 free_run 同构)

每 learn 步 = 64 agent 步 (1 窗)。窗内前向整窗处理 (时间核递归跨帧因果), 动作
逐帧从 z_bind 软采样, 环境逐帧执行; **下一窗感知 = 本窗动作的后果**。行动-后果
因果链完整, 带一窗滞后——窗口化处理的代价, 与 closed_loop/echo 的"生成后感知"
同构 (方案 4.1 的逐步循环是理想化表述, 窗口化是代码库既有粒度)。

### 2.5 W_t 物理: 冒烟实证驱动的修正

初始实现裁剪了 decorr/突触缩放/滑阈, 4 步内 rho_t4 68→88 直撞守卫墙 (100)——
静息态 z4≈常数帧, Hebbian 外积是固定秩 1 方向, 无 decorr 时单向累积, 守卫将成
为增益设定者 (第 79/83 轮排除的病态)。**修正: 完整移植 learning.py 的 free_run
W_t 物理**——W_t4 homeostatic 滑阈 (第 75 轮) + G8 双向突触缩放 (第 83 轮) +
超量 E decorr coef 0.2 (第 81 轮), 无 Oja/无 soft_norm (第 81 轮豁免, 递归增益
自由度归系统)。修正后 rho_t4 54→37→~54 稳定。这是**既有机制的移植, 非新机制**。

### 2.6 W_act 学习规则 (方案 4.1 步骤 5-6)

表达者三因子负号规则的动作域移植 (第 76 轮):

```
pred_self = softmax((zb_prev @ W_bind_self) * 4)     # 转移模型预测
eps_t = (zb - pred_self)²                             # 自洽转移误差
LP = eps_prev - eps_t                                 # 学习进步 (负时间差分)
phi = 0.5·(1 - tanh(50·LP))                           # 增益门控 [0,1]
surprise = phi                                        # 纯内部自洽 (无 W_lm)
dW_act = -(zb^T ⊗ one_hot(动作))·surprise             # 负号: 高惊喜抑制该行为
dW_act -= 0.1·(zb^T ⊗ softmax(pot))                   # 稳态抑制 (防动作垄断)
W_act += dW_act·(0.2·lm_lr_boost)·(0.5+intr_drive)    # intrinsic 并列调制
soft_norm 列归一 [0.8, 1.2]
```

具身域没有字节世界模型, 故 `wlm_err` 弱约束项移除, surprise 完全由内部转移模型
的自洽误差驱动——与方案的"自洽评估: W_bind_self 对 z_bind 转移的预测误差"一致。

## 五、结论: 世界没有唤醒静息态 — 机制已定位

**探针判定: 阶段 1 的"行动-感知关联建立"未发生; "世界唤醒静息态"论题在 500 步内
未获证实。** 但红线全过 (接口稳定、零 NaN、零死亡), 且阻塞机制被数据精确定位:

### 5.1 阻塞 1: bias 支柱在直接前馈半环, 感知进不了 bias 动力学 (结构性)

具身架构下 `z4 = mu4 + rec`, `eps4 = z4 − (percept@W_04 + bias) ≡ rec` 是**构造性
恒等** — W_04 的 PC 重建误差恒等于递归贡献, 与感知无关。bias 更新积分的是
`eps4.mean = rec.mean`, 而 rec 由 W_t 作用于 bias 主导的 z4 产生 → bias 只追踪
递归直流, 永不直接看到感知。世界确实进入 W_04 的 Hebbian 更新 (行范数
0.125→1.0), 但没有力把它传进 bias 积分。第 88 轮"去 DC 只治递归半环"的诊断在此
升级为: **bias 支柱的喂给半环 (eps4≡rec) 与感知完全解耦** — 不是修不修的问题,
是感知物理上到不了 bias 更新公式。

### 5.2 阻塞 2: 继承的深饱和把感知调制压缩 ~9 倍

静息 bias 把 z4 推到 rms 2.18, 65% 帧 \|z4\|>1 (sat 0.655)。分流抑制导数
1/(1+\|z\|)² ≈ 1/9 — 感知调制 (~0.46 std) 叠加在 bias (~1.7) 上, 经 L2 归一化
(方向为主) + 分流压缩后, z_bind 几乎只剩 bias 方向。W_bind_self 转移误差因此与
动作无关 (te_gap≈0), W_act 三因子负号规则无信号可学 → 动作均匀随机。这正是方案
风险 2 的预设诊断: "若 te 不变, 则 z_bind 没有编码环境感知" — 已证实, 根因是
深饱和而非 W_04 未更新。

### 5.3 阻塞 3: 环境参数慷慨, 无生存梯度 (方案自己的风险 1 实证)

随机游走即生存正收益 (4 块/32 格, 命中 12.5%, 电量增益 0.5 ≫ 衰减 0.01/步),
电量全程 1.88-1.90 无死亡窗。"行动维持存在"的压力不存在 → 感知-动作耦合无演化
动力。方案 3.1 的参数使阶段 1 判据 1 (行动偏置) 在**任何**策略下都不会由生存
压力自然涌现。

### 5.4 部分积极发现 (诚实的副产物)

1. **W_35 复活 12× (0.05→0.58)**: 无 G8 缩放后 Hebbian 重新激活 L5 前馈通路 —
   exp85 裁决 7 的"前馈链死亡"在具身模式下自然反转。但 z5 通路不参与行动回路
   (行动只经 z4→z_bind), 故未转化为行为信号。
2. **rho_t4 中段触顶 100.1 一次 (step 203)**: 静息常数帧的秩 1 Hebbian 推动 +
   decorr 0.2 平衡, 但未达新平衡, 在守卫附近漂移 — 递归增益是下一个不稳定点。
3. **系统活着且在学习**: z4_rms 上升、W_04/W_35 增长 — 内部动力学在响应世界,
   只是响应没有到达行动读出端。

## 六、下一步决策点

按方案自己的回滚条文 (风险 1/风险 2), 三个方向互斥, 需裁决:

- **A. 环境物理调整 (方案风险 1 回滚原文)**: 提高电量衰减速率 / 稀疏能量块,
  制造生存梯度 — 环境变更, 非模型调参, 不违反探针红线。直接检验"生存压力 →
  感知-动作耦合"是否涌现 (阶段 1 判据 1 的真测试)。
- **B. 接受负结果, 修正唤醒论题**: 阻塞 1 是结构性的 (eps4≡rec 与感知解耦),
  方案"bias 支柱会自然松动"的前提 (新信号进入 Hebbian 更新 → 打破平衡) 在
  bias 更新公式上不成立。若要走"唤醒"路线, 需架构变更 (如 bias 更新改感知重建
  误差驱动, 或 mu4 去 DC), 属架构裁决, 按守则先问再动手。
- **C. 延长探针**: 5000 步看 te_gap 是否从噪声中长出结构。但随机运动已保证生存,
  无压力即无演化动力, 预期不变 — 低价值。

**建议: 先做 A** (环境是方案的一部分, 参数调整是方案写明的回滚路径, 非上帝之手),
若 A 下仍无耦合, 再做 B 的架构裁决。**本报告不追加任何内部机制。**

### 7.1 探针 1: 环境饥饿 (`out/exp90_hunger`)

**变更**: 电量衰减 ×10 (0.01→0.1/步), 能量块减半 (4→2)。随机游走期望电量变化
-0.1 + 0.5·(2/32) = -0.0688 < 0 → 不再能生存。这是方案风险 1 回滚原文 (生存

**观测目标**: p_fwd 是否偏离 0.5; 电量是否出现"下降-回升-再下降"生存节律
(能量块重排 50 步 + 濒死-偶遇-回升循环)。

### 7.2 探针 2: bias 更新改 mu 对齐 (`out/exp90_biasalign`)

**变更** (用户批准的唯一架构级候选): bias 更新从积分 eps 改为 mu 对齐:

```
bias_i += η_bias · (mean_t(mu_l_i) − bias_i)
```

物理: 静息电位向平均输入靠拢, 感知自然调节内部基线。纯局部, 无外部目标。
**无自反馈**: mean(mu4) − bias = mean(percept@W_04) — bias 的自身值在差分中
消去, eps 积分支柱的 "bias→mu→z→eps→bias" 正反馈结构性切断, 门控/excess
随之移除 (它们防的正是支柱增长)。η_bias = 系统自身 lr_hebbian (首 50 步减半),
零新常数。活动基线 EMA 照常更新 (供 W_t 突触缩放, 避免陈旧基线)。

**观测目标**: bias_l4 是否随环境输入移动 (不再冻结); 是否间接松动深饱和
(sat 下降 / z_bind 重新响应感知差异)。

### 7.3 探针 3: z4 瞬时活动增益 (`out/exp90_z4gain`)

**变更**: 前向 z4 递归后施加瞬时活动增益 (非 EMA 慢基线):

```
gain = 1.0 / (1.0 + mean|z4|)
z4 = z4 · gain
```

纯局部瞬时归一化: 高活动自动降增益 (gain ∈ (0,1]), 低活动近恒等。窗口全局
标量, 零新状态。

**机制预分析** (诚实声明): z4 的下游消费大多尺度不变 (L2/rms 归一化), 增益的
直接作用面是 ① eps4 = z4·gain − mu4 (bias 更新与 W_04 学习) ② STP 资源消耗。
压缩 → eps4.mean 系统性变负 → **bias_l4 走低** → mu4 降低 → 饱和松动 —
即"间接去饱和"路径, 正是用户观测目标 (sat 从 0.67 下降, z_bind 不再只含
bias 方向)。z_bind 的响应差异能否恢复, 取决于 bias 下降量是否足以让感知分量
在 z4_n 方向混合中显形。

### 9.1 实现 (仅一处)

```
z4_dc = z4.mean(dim=1, keepdim=True)   # 窗口时间均值向量 ([1,S,a4] 时间维=1;

z4_bind = z4 − z4_dc                    # 移除 DC 方向
z4_n    = L2_norm(z4_bind)              # 再归一化 (由 _bind 内部完成)
z_bind  = relu(z4_n @ W_bind − θ) ...   # 原有路径不变
```

其余路径 (W_42/W_t*/eps/W_bind 学习/动作) 逐位不变 — 去中心只作用于前向
W_bind 输入。冒烟 (10 步) 已证实: cos_bind 0.947→~0.03 (DC 方向从输入移除),
cos_raw 保持 0.96 (对照), pca_bind ~0.6 (AC 散布增强但各向异性), 零 NaN。
