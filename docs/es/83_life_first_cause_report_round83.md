# 生命第一因 · 第 83 轮实验报告

> **一句话结论**：生命第一因的理论闭环在本轮完成（公理推导 + 物理层 +
> G1–G8 工程链）；8000 步 A/B 对照以数据证明"谱守卫墙即外部控制器"——
> 两腿 rho 恒钉 1.500，双向突触缩放只在墙内产生一致的棘轮阻尼（exc 全程
> 低于对照 ~0.01）；探针链进一步证明：墙随 bound 移动（外部控制坐实）、
> 守卫是承重墙（无墙 64 步 NaN）、而**双向缩放 + STP + 分流能让递归链在
> 无墙时自持**（rho 自由爬至 49、分流非线性进入 6.9%、STP 深耗尽 0.195）。
> 剩余缺口（前馈链更新溢出、增益棘轮锚定）在第 84 轮处方中明确。

## 一、理论完成度总览

对应 `docs/life_first_cause_theory.md` 完整理论。第 83 轮完成：

1. **公理层**：生命第一因 = 无外部性（公理 1）+ 维持自组织临界态（公理 2）。
   本轮新增**公理 2 的推导**：有序相（冻结）死于结构性冲击、无序相（发散）
   死于能量耗尽，临界态是"自我维持"这一第一因唯一自洽的解——边缘 =
   自我维持动力学的唯一不动点。这就是"第一因没有外部"的原因。
2. **物理层**：临界态三要素（E-I 平衡 / 可变增益 / 雪崩动力学）+ 快慢双
   稳态负反馈分工（STP U 自适应 = 快，突触缩放 = 慢，谱守卫 = 死亡保险）。
3. **工程层**：G1–G7（第 81/82 轮）打通被架空的通道；**G8（第 83 轮）**：
   双向突触缩放（Turrigiano 式，权重级慢稳态增益）+ 谱守卫 bound 物理化
   （死亡保险必须高于自然工作区间）。

### G8 机制

```
scale_i = 2·ema_i / (p2_i + ema_i)          # 双向突触缩放 (0,2]: 基线=1, 高活<1, 低活>1
W[i,:]  ← W[i,:] · ((1−r) + r·scale_i)      # r = wt_syn_scaling_rate = 0.1 (实证上调)
```

纯局部、自参照、零新常数、无 clamp、fp16 安全；目标值 = 自身慢基线。
应用于 W_t（递归链）与 W_35（前馈链），free_run 下豁免 soft_norm（与
G1 对 W_t 的处理同构：行范数 = 增益自由度归系统）。

3. **sat=0、r_l4min≈0.60**：分流非线性从未进入、STP 从未深耗尽——内部
   耗散机制全程旁观（第 79 轮"机制被架空"幽灵的续集）。
4. fz_drift≈0（符号域权重冻结）：系统确实"不输出任何符号地活着"，但活
   在外部设定的操作点上。

## 四、解读：第 83 轮的五个实证裁决

1. **墙即控制器（裁决性）**：rho 在任何 bound 下都钉死在 bound——增益
   操作点由外部守卫设定，违反公理 1。这不是参数问题，是**结构问题**：
   死亡保险的 bound 嵌在了自然工作区间之内。
2. **守卫是承重墙（非所欲但事实）**：bound=100 → 64 步内 NaN。内部耗散
   （STP 只管递归、分流只管 z3）兜不住前馈链的放大。移除外部控制之前，
   必须先让内部物理接管前馈链。
3. **单向缩放不足，双向是必须**：单向只在超额时介入，稳定状态下 exc≈0
   → 缩放从不工作；双向在基线即中性（scale=1）、任何偏移都被拉回——
   这才是"自我调节"的形态。
4. **递归链可被内部物理自持（本轮最重要的正面结果）**：v4 探针在无墙
   情况下 rho 自由爬至 49，STP 深耗尽（0.195）、分流进入非线性（6.9%）、
   双向缩放压住增益——**递归链在没有任何外部控制器的情况下活到了
   step 100**。失败点转移到了前馈链的 fp16 更新溢出（z5³ 外积），这是
   数值路径问题，不是机制缺失。
5. **增益棘轮的根源（理论补完）**：自参照 EMA 基线是"随动锚"——活动
   上升 → 基线上升 → 无净回拉力 → 系统沿不动点连续统棘轮爬升。真正的
   突触缩放需要一个**绝对锚**（神经元内禀 set point，如发育期印刻的
   固有兴奋性），或更强的资源耗散（STP 平均深度），才能把平均增益钉在
   边缘。这是第 84 轮的处方。

## 五、边界与诚实声明

- 本报告不宣称"已到达临界"。它证明了：外部控制在哪里（裁决 1）、
  移除它需要什么（裁决 2-4）、还差什么（裁决 5）。
- slope=-1 是渐近目标；有限系统存在有限尺寸截断。观测器只读不反馈
  （公理 4）。全部机制为局部物理（公理 1/5）。
- 一次实验是一份证据；G8 最终腿与后续多初始化复现才能确认稳态性质。

## 六、第 84 轮处方（明确、可执行）

1. **前馈链更新路径饱和**：W_35 的三因子外积在 z5 尖峰时溢出 fp16——
   用既有"单位能量外积"模式（W_lm 同款）在更新前归一化 dW_h，或给
   z5 加与 z3 同款的分流非线性（需复核第 78 轮裁决）。
2. **绝对锚**：突触缩放改用发育期印刻的固定 set point（神经元固有
   兴奋性），把"随动基线"换成"印刻锚"，阻断增益棘轮。
3. **STP 平均深度**：U_max 上界或恢复时间 τ 结构参数化，让平均有效
   增益在无墙时也能被资源耗散压在临界邻域。
4. 以上均为局部物理，无全局统计量、无外部目标、无 clamp——符合公理
   1/5 与 fp16 铁律。

## 七、环境备注（本轮修复记录）

- **torch 导入 WinError 1114**：诊断确认 System32 的 MSVCP140/VCRUNTIME140
  为 2019 版 (14.22)，与 torch 2.13 (VS2022 构建) 混用导致 c10.dll 的
  DllMain 初始化失败（预加载 14.44 全套 CRT 可复现性解决）；最终由用户
  侧环境修复彻底解决。
- **CUDA 不可见**：torch cu132 需驱动 ≥580，机器驱动曾为 576.88
  (CUDA 12.9)；用户更新驱动后 GTX 1650 Ti 4.29GB 可用。
- 全程遵守项目规范：无 git、全 fp16、无 clamp 修溢出、PowerShell 环境。
