# 第 94-97 轮: 行动-后果梯度进入 W_act — 完整实验链

> 裁决背景: exp93 (第 93 轮) 判定"在当前架构下, 行动-感知-后果闭环无法耦合
> 进行为" — W_act 学习信号 (纯内部转移误差) 与动作后果无关。用户授权打破
> 红线: 把"能量稳态偏差" (内稳态, 生命第一因的生存梯度) 加入 W_act 三因子。

## 一、机制 (最终版, exp97b)

```
感知通道 (能量) → dE = E[t]−E[t−1] → RPE = dE − EMA(dE)   [纯局部, 零物理常数]
      ↓ 因果移位 (rpe[t] = 后果[t+1], 严格滞后对齐)
W_act 三因子外积: dW_act = −(z_bindᵀ ⊗ (a_oh ⊙ w_rpe ⊙ φ))
      w_rpe: 命中帧 0.2 (弱抑制=保留) / 未命中活帧 1.5 (相对抑制=探索) / 死亡帧 0 (零外积)
      φ: LP 门控 (内部转移误差学习进步, 第 76 轮表达者基线)
```

修复链 (四刀, 每刀都有实证):
1. **去秩 1** (z4dc + bindac, 第 91/93 轮探针): W_bind 输入去中心 + 学习端
   同源 — cos_bind 0.95 → 0.03-0.08, z_bind 帧方向从恒定变分化。
2. **豁免 soft_norm** (exp97): soft_norm_preserve(W_act.T) 每步把列范数钉回
   1.008-1.016, 列差 0.07→0.005 (缩 14×) — 列范数 = 动作偏置自由度, 被
   安全网抹平。具身域 d_act=2 豁免 (字节域 256 列保持)。
3. **外积加权** (exp95): m_rpe 乘 surprise 会被 dW_act 单位向量归一化抹平
   (只保方向), 必须乘在外积 (a_oh ⊙ w_rpe) 上 — 方向偏置真实保留。
4. **极性修正** (exp97b): 命中帧 w=5 经负号 = 强抑制命中动作 (学反了),
   且未命中帧占 10 倍数量淹没列差。三态 0.2/1.5/0 给出真实对比梯度。

## 三、结论

1. **架构闭环已打通** (exp93 → exp97b): 感知 → 能量 RPE → W_act 外积 →
   列范数 → 动作偏置。行动-后果梯度第一次真实进入 W_act 学习路径。
2. **未到生存行为**: 偏置 0.058 太小。1500 步 × 64 帧 × 27% 活帧 ≈ 26000
   活帧, 命中 ~1200 帧 (4.6%)。命中 0.2 vs 未命中 1.5 的对比度积累太慢。
3. **升级路径** (未执行, 留给后续轮): (a) 延长至 5000+ 步; (b) 提高对比度
   (命中 0.1/未命中 2.0); (c) 命中帧直接 +Δ 强化 (对称极性, 非负号框架);
   (d) 环境加大生存梯度 (decay 0.10 → 0.15, 块 2 → 1)。
4. **字节域路径不受影响**: 所有修改在 scripts/exp_embodied1.py (探针脚本),
   model/dense/ 仅 W_act soft_norm 豁免按 d_act≤2 条件分支 (字节域 256 列
   保持原行为)。
