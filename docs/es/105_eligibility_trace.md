# 第 105 轮 (续): 突触资格迹落地 — 架构级变更, 冒烟通过

## 一句话
按用户裁决引入资格迹 (Eligibility Trace): 突触的"工作记忆" — 跨时间
窗口的因果绑定能力. 结构落地+200 步冒烟验证完成, 零 NaN, R=0 行为零变.

## 数学 (用户公式, 零修改)
- E ← γ·E + pre⊗post   (γ=ELIG_GAMMA=0.95, 半衰期~13步)
- ΔW = η·R·E            (R=延迟生存信号)

## 实现决策 (逐条记录, 有实证理由)

1. **叠加而非替换**: 迹作为 Hebbian 外的附加项 — ΔW = η·dW + η·R·E.
   替换式会把现有更新完全换成迹项, R=0 时训练冻结实测
   (dW_lm_rel=0.00000), 违反"R=1.0 维持现有行为". 叠加式 R=0 时
   精确回到基线 (dW_lm_rel=0.02501 vs 基线 0.025).

2. **R 默认值 = 0.0 (非 1.0)**: 用户的公式稳态时 E 幅度 = dW/(1-γ) ≈
   20×dW (单位向量化后的 dW 进迹, 滑均收敛到 0.18 则 1/6×). 没有任何
   标量 R 能同时吸收这两个相反的尺度差 (20× vs 1/6×), R=1.0 必然
   改变行为. 唯一满足执行指令 3 ("默认维持现有 Hebbian") 的取值:
   R=0 → 迹每步照常积累 (结构活着), 但不参与更新. **生存环境接入时
   设 net._survival_signal = 环境标量, 迹通道启用** — 20× 幅度由
   生存信号的自然小量级承担.

3. **单位增益归一化的尝试被否定**: E←γE+(1-γ)dW + 幅度补偿因子在
   fp16 下爆炸 (E_norm 近零时 dW_n/E_n 放大 1000 倍 → NaN). 放弃.
