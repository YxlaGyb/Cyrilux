# Dense PC 语言破局战役: 秩 1 锁断裂记 (2026-08-06)

## 一句话战果

**表示层有效维度 (PR_eff) 从 1.5-2.0 撑开到 4.5-26, 字节命中率 12.3% → 23.5%, 60000 步全程无 NaN。** 三层机制: 频率锚点锁时间核 + 超量 E 切权重主成分 + W_lm 三件套防破局后爆炸。

## 战役背景

model67 旧架构 (15.9 万步) 命中 0%; 4 数据集 60000 步版本 (model67_4ds) 命中 12.3% 后焊死。诊断结论: 表示层 PR_eff (有效维度数) 仅 1.5-2.0 —— **网络本质上只用 1-2 个方向表示一切**, 容量锁不解开, 语言不可能出来。

### 前提勘误 (第 1 轮)

"PR_eff = 4.0" 是幻觉: 旧架构 L5 拆 4 块微柱, "4" 只是**块数** (块间时间子采样), 不是维度利用。全维实测: L2=2.04 / L3=1.54 / L5=1.54。目标从"跳出 4.0"修正为"打破 1.5-2.0 的秩 1 锁"。

## 根因链 (逐层实测定位)

```
Hebbian 外积秩 1 累积
  → 时间核 W_t 谱秩 1 (top1 sv 2.0→20+, u⊗v^T 结构, 行正交但谱集中)
  → 递归把 z 拉向主方向 (z 秩 1)
  → 每层 W 行收敛 ±w (有符号 cos≈0 被符号随机掩盖, 绝对 cos 134 倍于随机)
  → 下游投影秩 1 (mu2 协方差 top1 占 89%)
  → PR_eff 焊死 1.0-2.0
```

关键认知: **行间 cos 无法检测 ±w 收敛** (符号随机), 这是所有"去相关"直觉失效的数学根源。侧抑制 (M@z5)、行去相关 (E@dW) 全部验证为只能"维持分化", 不能"创造分化"。

## 三层机制 (缺一不可, 每层都有失败迭代)

### 1. 频率锚点 (时间核高频抑制项)

时间核更新中, 静止帧 (Δz = z_t - z_{t-1} 范数 < z 平均范数×5%) 完全不参与外积。语义: "你总是重复, 连接就被削弱" — W_t 被迫只从有变化的帧学习转移。

```python
dz_n = dz.norm(dim=-1)
th = (post.norm(dim=-1).mean() * 0.05).unsqueeze(0)  # 绝对阈值
s = (dz_n < th).to(dz_n.dtype)  # 静止帧 → 0, 动态帧 → 1
dW_t = (_rms(pre).T @ (_rms(post) * s.unsqueeze(-1))).mean(0) / (S-1)
```

失败迭代 (全部实测):
| 方案 | 结果 |
|------|------|
| mean×0.01 阈值 + 0.9 衰减 | 无帧触发 (随机流差分太大, 静止占比 0.000) |
| 0.9 衰减 (分位阈值) | 无效 (只削 10% 幅度, 方向不变, 外积仍主方向) |
| 分位阈值 + 清零 | 100 步 24.1 后塌 (塌缩后"动态帧"也在主方向, 分位失效) |
| **绝对阈值 + 清零** | **W_t2 top1 20.3 → 2.0 锁死** ✓ |

### 2. 超量 E 机制 (权重去主成分投影)

每步对每层权重: `W -= β·(W@v)⊗v`, v = W 的 top1 奇异方向 (幂迭代 3 次)。

```python
v = torch.randn(W.shape[1], 1, device=dev) * 0.01
for _ in range(3):
    v = W.T @ (W @ v); v = v / (v.norm() + 1e-8)
c = W @ v                       # 每行在 top1 方向上的投影系数 (含 ± 符号)
W -= 1.0 * (c @ v.T)            # β=1.0 超量抑制
```

失败迭代:
| 方案 | 结果 |
|------|------|
| β=0.5, E=|cos| 中介幂迭代 | 被 Hebbian 正反馈覆盖 (行 |cos| 推到 0.048 但激活仍秩 1) |
| β=1.2, E=|cos| 中介幂迭代 | 334 步 E_l5 NaN (3 次幂迭代收敛不充分, v 含噪声被放大) |
| **β=1.0, v 直接从 W 幂迭代** | **500 步 PR_eff 1.0→40.6, W_t top1 11.4→3.1, 无 NaN** ✓ |

E 矩阵 (E_42/E_23/E_l5/E_t2/E_t3/E_t5) 保留但只学 |cos| 作诊断。

### 3. W_lm 三件套 (破局后必改)

破局后表示层能量暴涨 (PR 高维 vs 旧共线), 连锁引爆 4 个问题:

| 问题 | 根因 | 修复 |
|------|------|------|
| 熵死锁误杀 | 旧检测器把"熵 0 + 命中 15%"当死锁 | 命中 >5% 不算死锁 |
| 熵锁 0.18 | logits ±67 (√4096≈64 维放大), softmax 饱和 | 输出乘 1/√(4a4) (CLAUDE.md: 投影溢出 → 1/√H) |
| 熵 5.5 不降 | 0.999 指数遗忘吃掉高维稀释的 dW (W_lm 行范数冻结 1.195) | 更新外积用 _rms(zh) |
| W_lm_2 NaN (800 步) | 长文本/padding 单步 dW 突爆 (范数 1.2→NaN 一步爆) | dW 归一化单位方向 (W_04 同款幅度-方向解耦) |

## 生成验收 (部分达成)

中文 prompt 字节流**正确延续 10-16 字节** ("今天天气很好, 我们一起去" 逐字节复现) 后退化碎片。从"碎片乱码"进步到"N-gram 记忆", 未到"合理词干泛化"。下一战场: W_lm 从记忆到泛化。

## 踩坑记录 (fp16 专精)

- **归一化吞增量**: dM Frobenius 归一化 → 增量 3e-8 被 fp16 舍入 (最小正规数 6.1e-5), M 从没学过。装饰性失效的两例: 侧抑制 M, E=|cos| 加权平均被 ± 抵消
- **E@dW 求和放大**: E 元素 0.1 时 1024 项和 ≈ 102·dW, ×0.2 = 20 倍反向驱动 → NaN。行归一化解决
- **高维稀释**: 4096 维输入的 dW 每元素小, 0.999 遗忘吃掉 → 行范数冻结。输入归一化解耦维度
- **幂迭代脆弱**: 3 次迭代的 v 含噪声, β>1 时放大发散。v 必须从目标矩阵直算
- **绝对阈值 > 分位阈值**: 塌缩后差分整体变小, 分位永远选中 30%, "动态帧" 也在主方向。绝对阈值让塌缩 → 静止占比暴增 → 学习信号枯竭 → 自然平衡
