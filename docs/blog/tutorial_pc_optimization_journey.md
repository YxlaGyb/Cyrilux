# 一个预测编码模型的死而复生：从 PPL 五百万到能拼单词

> 训练了 127 万步的模型，困惑度 17,409，生成的文本全是乱码。  
> 问题不在训练量，而在三个互相锁死的设计缺陷。  
> 修复不靠梯度下降，靠的是 40 年前几个神经科学家在黑暗的实验室里发现的东西。

---

## 起点：模型什么也没学到

这是一个预测编码（Predictive Coding）模型。它的工作原理和 GPT 完全不同——没有反向传播，没有 Transformer，只有局部的 Hebbian 突触更新和全局的多巴胺调控。感官前端把原始字节转换成特征，隐藏层预测下一个感官状态，预测误差驱动学习。

训练 20,000 步后，我们测试了它。

困惑度（Perplexity）是 5,277,685。健康值应该低于 300。模型对任何输入只预测一个字节——`C`（ASCII 67）。不管你喂给它"Hello world"还是"import torch"还是中文，输出永远是 `C`，概率 100%。熵为零。

这是模式坍塌。模型死了。

---

## 第一刀：LM Head 为什么只喊一个字母

模型里有一个叫 LM Head 的东西，负责把隐藏层的活动状态映射成"下一个字节是什么"的预测。它是一个线性层：512 个隐藏神经元 → 256 个输出分数。

它的学习规则是 Hebbian 的：

```
目标字节:   权重 += 学习率 × 隐藏层活动
非目标字节: 权重 -= 学习率 × 0.01 × 当前权重
```

目标字节每次加固定量，非目标字节只衰减 1%。两边差了 100 倍。训练数据里最常见的字节（比如 UTF-8 续字节 `0xe5` 和字母 `C`）每次出现都加分，其他 254 个字节几乎从来没被加过，但每次都是"非目标"被减一点点。20,000 步后，高频字节的权重飙到天上，其他归零。模型永远只会喊那几个最常见的字节。

标准的修复是加一个 softmax 归一化，用交叉熵损失。但这是一个**生物启发的模型**——大脑不做 softmax。之前已经淘汰过交叉熵了，不能再加回来。

### 大脑怎么防止"只会喊一个答案"

多巴胺神经元不编码"奖励"，它们编码**预测误差**。当结果完全符合预期，多巴胺沉寂——不应该再触发学习。只有当你**猜错**的时候，才需要学。

突触层面还有一个叫**异突触长时程抑制**（heterosynaptic LTD）的现象。当一个突触被强化（LTP）时，同一树突上的相邻突触会自动削弱。因为突触维持需要共享的局部资源——钙离子、蛋白质、能量。一个增强，另一个必须减弱。

这两个机制合起来就是修复方案：

1. **误差门控**：先算 `pred_byte = argmax(logits)`，如果 `pred_byte == target_byte`，学习率降到 10%。猜对了就别再学了。
2. **异突触竞争**：目标字节做 LTP 的同时，错误预测的字节做 LTD。它猜错了——它"用了不该用的资源"，应该被削弱。

20,000 步重新训练后，熵从 0.00 恢复到 5.33（最大 5.55）。LM Head 不再坍塌了。

但困惑度仍然很高。模型的隐藏层对不同输入产生**完全相同的活动模式**。LM Head 能看到的信息只有"全局字节频率分布"——它知道 `e` 比 `z` 常见，但不知道"Hello w"后面应该是 `o`。这是下一个问题。

---

## 第二刀：隐藏层为什么是死的

我们在诊断时发现一个令人震惊的事实：隐藏层 512 个神经元，预测误差（eps）的均值只有 0.03。几乎为零。

追溯代码，找到了这四行：

```
# 非感官层神经元: z = mu, eps = 0
non_sensory = alive & (layer > 0)
state[non_sensory, Z]   = state[non_sensory, MU]   // 活动值 = 预测值
state[non_sensory, EPS] = 0.0                        // 误差清零
```

隐藏神经元的预测误差被**故意清零**了。设计者的想法是"非感官神经元等于自己的预测"——这在哲学上优雅（预测编码的精髓：大脑推断世界状态，推断就是状态），但在生物学上是错的。

### 生物神经元有时间常数

一个真实的锥体神经元接收前馈输入（丘脑→皮层）和反馈预测（高层→低层）。它的膜电位是**两者的整合**，不是单纯等于预测值。膜电位有时间常数 τ——突触输入改变电位，但不是瞬间完成的。

这个时间差就是学习信号。

```
修复前: z = mu           (z 瞬间等于预测)
修复后: z = 0.3×z_old + 0.7×mu   (z 向预测靠拢, 但有惯性)
         eps = z - mu ≠ 0         (误差回来了)
```

只有一行代码的修改。隐藏层的 eps 从 0.03 跳到了 0.5 以上。学习信号活了。

### 阈值棘轮

还有第二个死因。每个神经元有一个发放阈值——活动超过阈值才算"发放"。warmup 阶段大量感官事件涌入，所有神经元被迫发放，阈值调节机制开始工作：

```
发放时:    阈值 += 0.05 × (发放率 - 目标率)  ≈ 每秒上升 0.05
不发放时:  阈值 += 0.05 × (0 - 目标率)       ≈ 每秒下降 0.0005
```

上升比下降快 100 倍。warmup 结束后阈值卡在 12.3，最大值 128。隐藏层永远无法再发放——它们沉默了，而且永远沉默下去。

修复：硬上限 0.5。当 |预测误差| > 0.5 时总是可以发放。生物对应：不应期后膜电位完全重置，不累积。

### 侧抑制：让不同神经元做不同的事

修复后隐藏层活了过来。但新问题出现了：所有 512 个隐藏神经元对任何输入产生几乎相同的活动模式。英语散文和 Python 代码的余弦相似度是 0.99。

大脑怎么解决这个问题？**侧抑制**——当一个神经元发放时，它通过抑制性中间神经元压制邻居。结果只有最强的 5-10% 神经元在任一时刻活跃。这就是稀疏编码。

我们在隐藏层加了 k-WTA（k-Winner-Take-All）：每层独立选出 |z| 最高的前 10% 作为赢家，其余衰减到 10%。不同输入激活不同的赢家子集——为输入选择性创造了必要条件。

## 第三刀：127 万步训练为什么还不如 1.7 万步

完成上述修复后我们重新训练了几个模型：

| 模型 | 训练步数 | PPL | 状态 |
|------|---------|-----|------|
| model5 | 17K | 256 | CE=5.54，接近随机 |
| model6 | 40K | 315 | 开始变差 |
| model7 | 127万 | 17,409 | 极度自信地全错 |

**训练越多反而越差。** model7 训练了 127 万步，困惑度反而爆炸到 17,409。它的熵只有 2.74，远低于健康的 5+——说明它对自己错误答案极度自信。

为什么会这样？

### MU 和 Z 的故事

在预测编码模型中，每个隐藏神经元有两个关键变量：

- **MU (预测值)**：`scatter_add(权重 × 感官输入)`——纯前馈，由当前输入直接计算
- **Z (活动值)**：MU + 惯性平滑 + k-WTA 竞争——最终呈现给下游的状态

我们测量了所有四个模型的 MU 和 Z 对两个不同输入（英语 vs Python 代码）的余弦相似度：

```
model4: MU_EN vs MU_CODE = 0.79  ← MU 能区分输入
        Z_EN  vs Z_CODE  = 0.84  ← Z 丢失了差异

model7: MU_EN vs MU_CODE = 0.86  ← 127万步训练后，MU 仍然有选择性
        Z_EN  vs Z_CODE  = 0.89  ← 但 Z 把它平滑掉了
```

**MU 天生携带输入选择性，Z 把它杀了。**

当"Hello world"和"import torch"喂进模型时，MU 产生的是不同的向量。感官前端确实从不同的字节序列中提取了不同的特征模式。随机连接虽然粗糙，但不同的隐藏神经元连接的是不同的感官神经元子集——MU 已经携带了微弱的上下文差异。

但 Z = 惯性 × 历史 + k-WTA 竞争把差异平滑掉了。惯性让 Z 更依赖于自身的历史而不是当前输入。k-WTA 总是选出同一批赢家——那些在早期训练中偶然获得优势的神经元。LM Head 接收的是一个对所有输入几乎相同的向量。

### 关键实验：让 LM Head 直接看 MU

我们做了一个实验。加载 model5（17K 步训练），把 LM Head 的权重清零，冻结隐藏层（不让它学新东西），然后让 LM Head 用 MU 作为输入重新训练。

**只训练了 2000 步，耗时 68 秒。**

结果：

```
原始 model5 (Z→Z, 17K步): PPL=256,  top-1=~0%
MU 重训  (MU→MU, 2K步): PPL=208,  top-1=12.0%
```

困惑度下降了 19%，top-1 预测准确率从 0% 跳到了 12%。CE Loss 从 5.54 降到了 5.34——**首次低于随机基线 5.55**。模型真正在学了。

生成的文本也变了。修复前是纯乱码，修复后：

```
"Hello" → "Hellomrcorcrc euyuercoae fsfcyo ciifa affinme"
"import " → "import uyymifmirhiccsysihryrltslumirrhrorr molu"
```

字母组合成了单词状结构——连续的字母序列 + 空格分隔。虽然拼写是乱编的（"euyuercoae"），但这是一个婴儿级语言模型：它学会了字母的分布规律和空格的结构功能。

### 四个模型全部验证

我们对 model7 做了同样的操作——清零 LM Head，用 MU 重训 2000 步。结果：

| Model | 隐藏层训练 | 原始 PPL | MU PPL | 改善 |
|-------|-----------|----------|--------|------|
| model4 | 52K | 306 | **210** | +31% |
| model5 | 17K | 256 | **206** | +19% |
| model6 | 40K | 315 | **203** | +35% |
| model7 | 1.27M | 17,409 | **191** | **+99%** |

**model7 从最差变成最好。** 127 万步的隐藏层训练没有浪费——神经网络在那 127 万步里学会了更丰富的感官特征编码。但旧的 LM Head（在 Z 上训练）把这些知识全扔掉了。换成 MU 后，只用了 2000 步就全部释放出来。

model4 有最高的 top-1 准确率（15.8%）——它的 52K 步隐藏层训练在"质量"和"数量"之间达到了最佳平衡。

## 第四刀（未完成）：让选择性在训练中自己长出来

当前的修复是事后补救——训练完后把 LM Head 切到 MU。理想的方案是让选择性在训练过程中自然涌现。

### BCM 理论

1982 年，Bienenstock、Cooper 和 Munro 提出了一个突触可塑性规则：

```
Δw = x × y × (y - θ_M)
```

θ_M 是神经元近期活动量的滑动平均。它不是固定的阈值，而是**每个神经元自己的历史**。

- 神经元活动量 y > θ_M → LTP（增强），同时 θ_M 上升
- 神经元活动量 y < θ_M → LTD（削弱），θ_M 下降

效果：**吃饱了的神经元自动变挑剔，饿着的神经元自动变不挑剔。**

眼优势柱在发育关键期是怎么形成的？最初 V1 的神经元对左眼和右眼都有响应，初始差异微乎其微（可能只差 2%）。BCM 规则下，稍微偏好左眼的神经元获得 LTP，对左眼更强，θ_M 上升。θ_M 升高后，右眼输入自动触发 LTD（因为右眼产生的 y 现在低于新的 θ_M）。循环放大——最终一个神经元变成纯左眼，隔壁变成纯右眼。

我们的 Hebbian 学习没有这个"自限"机制。赢家通吃，赢家越吃越胖，最后所有输入都把同一个赢家喂胖——所有人变成了同一个人。

加上 BCM 调制后：

```
Δw = 学习率 × 预测误差 × 前突触活动 × (1 - 4 × 滑动平均活动量)
```

长时间活跃的神经元学习率降到零甚至负值——自动把"市场份额"让给其他神经元。选择性不需要手动设计，它自己从竞争中长出来。

## 性能优化：消灭 2000 次 GPU 同步

修功能的同时也修了性能。在诊断过程中发现几个热点函数用 Python for 循环 + `.item()` 调用来处理 GPU 张量。每次 `.item()` 触发一次 GPU→CPU 同步——在 100K 元素上做这个，几千次同步加起来几秒钟就没了。

向量化的手段：布尔掩码替代 Python 循环、按神经元分组批量写入替代逐元素更新、`torch.topk` 一次定位替代 while 循环逐次扫描。不是这个文章的重点，就不展开了。

## 总结

一个预测编码模型从完全坍塌到 PPL 208 的优化之旅，涉及三个层面的修复：

**LM Head** — 误差门控防止"猜对了还继续加分"，异突触竞争防止"一个答案镇压所有其他"。

**隐藏层** — 膜电位惯性创造学习信号，阈值硬上限防止不可逆沉默，k-WTA 侧抑制创造稀疏表示。

**输入源** — 发现 MU 有选择性而 Z 没有。让 LM Head 看 MU 而不是 Z，127 万步积累的隐藏层知识被瞬间释放。

四个机制全部来自真实神经科学：多巴胺预测误差（Schultz, 1997）、异突触 LTD（Lynch, 1977）、膜电位时间常数、BCM 滑动阈值（1982）。没有 softmax，没有交叉熵，没有反向传播。

127 万步中最差的模型，换一个视角看就成了最好的。
