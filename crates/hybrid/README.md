# hybrid

English | [中文](README.zh.md)

## Summary

`crates.hybrid` implements the runtime engines of the dense PPA (perception-prediction-action) closed loop. `forward.py` owns `ForwardEngine`, which walks the activation path from the byte input up through layers L0 to L6, applies the temporal recurrence kernels, binds sparse concept slots, and performs autoregressive continuation and generation. The dynamic-neuron mechanisms, topology pruning and memory-unit birth and death, live in the sibling crate `crates.neuron`. The per-domain learning updates live in the sibling sub-crate `crates.hybrid.learning`. Together these engines consume the network and configuration that `crates.model` declares and drive it through pure-Hebbian, no-backprop learning.

## Use this package

The engine constructors take a single network and keep a reference to it.

| 导出 | 形状 | 含义 |
|---|---|---|
| `ForwardEngine(net)` | Engine | Holds the network and drives perception, inference, binding, and generation. Constructed automatically by `HybridPCNet.__init__` and exposed as `net.forward_engine`. |

Forward and generate.

| 导出 | 形状 | 含义 |
|---|---|---|
| `engine.forward(byte_ids)` | Feed-forward | Inference feed-forward. Returns the future prediction deviation with ACh off and full determinism. |
| `engine._predict(byte_ids, store_state, is_inference)` | Core feed-forward | Perception, Foldiak decorrelation, decentralizing, and incremental prediction. |
| `engine.generate(prompt, n_tokens, temperature, dev)` | Generation | Steps the model over a prompt string and returns generated bytes. |
| `engine.continuation(byte_ids, n_gen, temperature, rep_backstop)` | Autoregressive continuation | Shared by training rollout and validation. Batches over an input prefix and returns the appended tokens. |

## Understand the implementation

`ForwardEngine._predict` is the single activation path. It one-hot encodes the byte sequence at L0, applies the temporal kernels `W_t*` via `_recurrent` (a pure matmul with per-layer normalization), ascends through L4, L2, L3, L5, and L6, applies a Foldiak anti-Hebbian decorrelation at L5, and routes a decentralised z5 to the readout while the raw z5 feeds `W_diff` for world-model prediction errors. In free-run mode the external input is zeroed and the activity is driven entirely by internal recurrence and three additive oscillators, while the optional STP resource dynamics gate the recurrence. `_bind` projects z4 through `W_bind` into sparse concept slots with a top-k winner-take-all and exposes the resulting action potential through `W_act`.

`continuation` reuses the same logits pipeline for both training and evaluation. It can take temperature as a tensor to divide on-GPU with no scalar sync, applies an optional repetition backstop that masks cyclical bytes, and enforces UTF-8 legality by masking forbidden continuation bytes with pre-built masks. Multiple-step-commit telemetry is gated behind an opt-in flag.

`crates.neuron` owns topology remodelling and the memory-unit life cycle: how a remodelling round permutes a layer's row-mapped weights together with their downstream columns, and how the memory units are born and die. This package holds no remodelling logic: the orchestrator polls `net.maybe_prune(step)` and the network delegates to `net.pruner.decide()` and `net.pruner.compact()`.
