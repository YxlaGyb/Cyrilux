# hybrid

English | [中文](README.zh.md)

## Summary

`crates.hybrid` implements the runtime engines of the dense PPA (perception-prediction-action) closed loop. `forward.py` owns `ForwardEngine`, the entry point: `_predict` builds the environment and runs the graph that `forward_graph.py` declares. That graph names the activation path from the byte input up through layers L0 to L6, the temporal recurrence kernels, the sparse concept-slot binding, and performs autoregressive continuation and generation. The dynamic-neuron mechanisms, topology pruning and memory-unit birth and death, live in the sibling crate `crates.neuron`. The per-domain learning updates live in the sibling sub-crate `crates.hybrid.learning`. Together these engines consume the network and configuration that `crates.model` declares and drive it through trace-modulated, no-backprop learning.

## Use this package

The engine constructors take a single network and keep a reference to it.

| Export | Shape | Meaning |
|---|---|---|
| `ForwardEngine(net)` | Engine | Holds the network and drives perception, inference, binding, and generation. Constructed automatically by `HybridPCNet.__init__` and exposed as `net.forward_engine`. |

Forward and generate.

| Export | Shape | Meaning |
|---|---|---|
| `engine.forward(byte_ids)` | Feed-forward | Inference feed-forward. Returns the future prediction deviation with ACh off and full determinism. |
| `engine._predict(byte_ids, store_state, is_inference)` | Core feed-forward | Thin shell: builds the environment and runs the declared graph. Perception, Foldiak decorrelation, decentralizing, and incremental prediction now live in `forward_graph.py` as declared ops. |
| `engine.generate(prompt, n_tokens, temperature, dev)` | Generation | Steps the model over a prompt string and returns generated bytes. |
| `engine.continuation(byte_ids, n_gen, temperature, rep_backstop)` | Autoregressive continuation | Shared by training rollout and validation. Batches over an input prefix and returns the appended tokens. |

## Understand the implementation

`ForwardEngine._predict` is the single activation path. It one-hot encodes the byte sequence at L0, applies the temporal kernels `W_t*` via `_recurrent` (a pure matmul with per-layer normalization), ascends through L4, L2, L3, L5, and L6, applies a Foldiak anti-Hebbian decorrelation at L5, and routes a decentralised z5 to the readout while the raw z5 feeds `W_diff` for world-model prediction errors. In free-run mode the external input is zeroed and the activity is driven entirely by internal recurrence and three additive oscillators, while the optional STP resource dynamics gate the recurrence. `_bind` projects z4 through `W_bind` into sparse concept slots with a top-k winner-take-all and exposes the resulting action potential through `W_act`.

`forward_graph.py` is the declaration layer. `ForwardGraphs.declare()` emits one `crates.graphs.Graph` whose ops are the named steps of the activation path (25 of them are the `crates.kernels.cascade` operators, four are `crates.kernels.align` views), `_inputs()` names every tensor the graph reads, and `writes` lists the network attributes that `crates.graphs.apply_writes` sets after the run. A non-free variant declares 213 ops (214 with the `mu3_noise` step), a free-run variant 237 (238), with the 63 memory and 63 novelty steps unrolled as one node each. The graph is cached and fingerprinted per variant and per parameter and buffer name sequence, so two calls with the same shapes and weights reuse one graph; the fingerprint is a reproducibility record and no learning signal reads it. `ForwardGraphs.clear()` exists but no call site uses it yet: a structural event (a change of shape, row count or buffer topology) therefore keeps the cached graph until the wiring lands. The short `writes` table (`store_state=False`) is likewise unreachable from the current call sites, which all pass `store_state=True`; it is kept to match the signature, not for compatibility.

`continuation` reuses the same logits pipeline for both training and evaluation. It can take temperature as a tensor to divide on-GPU with no scalar sync, applies an optional repetition backstop that masks cyclical bytes, and enforces UTF-8 legality by masking forbidden continuation bytes with pre-built masks. Multiple-step-commit telemetry is gated behind an opt-in flag.

`crates.neuron` owns topology remodelling and the memory-unit life cycle: how a remodelling round permutes a layer's row-mapped weights together with their downstream columns, and how the memory units are born and die. This package holds no remodelling logic: the orchestrator polls `net.maybe_prune(step)` and the network delegates to `net.pruner.decide()` and `net.pruner.compact()`.
